# 0.21.1 — 混合检索结果徽标对齐

## 需求描述

搜索结果中的“语义 + 词法”和“距离”徽标会因会话标题长度而改变横向位置；空间不足时徽标文字还会折行，导致卡片间显示不一致。

## 方案

调整混合检索结果卡片标题栏布局：标题占据可收缩的剩余空间；命中通道和距离徽标作为右侧固定宽度组排列，徽标文字不折行。语义/词法命中数据、距离值和检索排序均不变。

- `server/apps/web/src/routes/search.tsx`
- `server/develop-doc/0.21.1/plan.md`
- `server/develop-doc/0.21.1/summary.md`

3. 标题可使用剩余宽度展示，不覆盖或挤压徽标组。
4. 根目录 `npm test` 与 `npm run build` 全部通过。
