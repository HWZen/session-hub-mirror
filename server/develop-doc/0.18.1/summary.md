## 与计划的偏差

1. 首轮实现（日期 `Input` 外包定宽容器 + 创建/更新成组）后，两组仍按 `flex-wrap` 实际断行：第一行是「标题 / 来源 ID / 创建组」、第二行只剩「更新组」，两组跨行不对齐；用户复核后调整为**文本过滤与日期过滤各占一行**，创建、更新两组固定同行成对展示。
2. 换行兜底仍由 `flex-wrap` 承担（窄屏下「更新」组可能折到第三行），不引入「更多筛选」折叠。
