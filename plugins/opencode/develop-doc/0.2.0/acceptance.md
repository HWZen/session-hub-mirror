# OpenCode 0.2.0 验收摘要

V1 / V2 隔离宿主验收覆盖插件加载、快照上传、历史扫描、生命周期、删除镜像、取消、重载与清场。原始 HTTP payload、模型调用、环境路径和宿主快照由验收者私有保管；可复用测试代码保留在 `scripts/acceptance/`。

历史 V1 全量 E2E 为 37 个断言中的 35 个通过，模型轮次与工具覆盖两项受宿主系统提示组装 TypeError 阻塞；不能描述为全量 E2E 全绿。版本完成记录见 `summary.md`。

本次 0.23.0 整合另行运行根测试与构建，结果记录在服务端 0.23.0 完成总结，不混用为本版本宿主 E2E 结果。
